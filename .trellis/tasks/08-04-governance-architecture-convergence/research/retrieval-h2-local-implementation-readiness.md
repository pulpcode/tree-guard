# H2 本地混合召回实现就绪记录

## 当前结论

H2 已完成“可受控执行”的工程实现，但正式 B 尚未运行，因此当前只有工程可行性结论，
没有召回能力结论，也不具备生产资格。

## 已冻结实现

- 模型、revision、权重摘要、query instruction、CLS/L2、512维、CPU/float32 和
  batch=16 绑定到独立 `H2EmbeddingProfile`；
- 节点与查询检索文本沿用 H1 版本，R2 lexical、Top-40、锚点门、排除过滤和
  1:1 固定 RRF 不变；
- H2 使用独立 profile、index、query embedding 和 candidate-set 合同，拒绝模型、
  树、文档、profile 或文件字节漂移；
- 索引和逐项 B 结果只能写入 `0600`、不可覆盖的私有 JSON；公开输出只保留固定
  code、聚合计数、指标、合同摘要和运行时聚合；
- 默认项目依赖没有加入 torch/transformers，本地模型只能从已校验的隔离快照加载，
  不产生网络请求。

## 预检结果

- 冻结数据：733 节点、28 条执行集、20 条有目标；
- A 聚合字节与确定性重放一致；
- 预注册门槛遗漏在原 A 报告中的“词面基线 Recall@8”已在 B 前通过零模型重放固定
  为 4/4，未读取或公开逐项内容；
- B 计划索引调用 46 个 batch，query 调用最多 28 个，另对首个有效 query 做一次
  相同输入向量重放检查；
- 预检状态为 `PREFLIGHT_READY`，`model_called=false`、
  `formal_b_executed=false`。

## 正式 B 门禁

正式运行必须同时显式提供执行批准标志、冻结模型快照、一个索引输入或新索引输出、
以及私有逐项结果路径。输出路径预检在模型加载前完成，既有文件不得覆盖。运行超过
30 分钟、向量重放不一致、索引/profile 漂移、合同失败或私有写入失败均只形成工程
错误，不形成能力结果。

正式 B 仍需单独批准；不得因为本记录的 PASS 测试或运行时 smoke 宣称 H2 已提高召回。
