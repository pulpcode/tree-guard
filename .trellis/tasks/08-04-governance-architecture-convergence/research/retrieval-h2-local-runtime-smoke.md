# H2 本地运行时无语义 Smoke 结果

## 范围

本次只验证冻结本地模型 profile 在外网开发机 CPU 上能否加载、生成规范化向量并
确定批大小；不读取 H2 场景、Oracle 或逐项 A 结果，不运行召回或准确率实验。

## 冻结运行时

- Python 3.11.15，独立临时环境；
- torch 2.2.2；
- transformers 4.44.2；
- huggingface-hub 0.24.7；
- safetensors 0.4.5；
- numpy 1.26.4；
- 模型、revision、权重摘要、query instruction、CLS/L2、512维、CPU/float32 与
  H2 预注册一致；
- 无语义固定文本 smoke 后，批大小冻结为 16。

## 聚合结果

- 状态：PASS；
- 相同输入两次向量逐值一致；
- 模型加载约 19.3 秒；
- 两个 batch 16 推理合计约 4.4 秒；
- 峰值 RSS 约 502 MB；
- 未运行 H2 A/B，未形成任何能力结论。

## 限制

本机时间和内存仅用于工程可行性估算，不是跨机器门槛。正式 B 仍须在冻结 runner、
索引和聚合输出完成审查后单独批准，且只能执行一次有效运行。
