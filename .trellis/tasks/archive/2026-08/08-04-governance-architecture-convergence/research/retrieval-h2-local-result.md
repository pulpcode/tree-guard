# H2 本地 BGE 混合召回首次有效结果

## 结论

首次且唯一一次正式 H2 B 为有效运行，能力判定为 `FAIL / H2_REJECTED`。本地模型
能够稳定加载、构建索引、生成一致向量并完成固定融合，但没有改善预注册的召回主指标。
该结论不代表所有向量召回均不可行，只否定当前冻结的模型 profile、H1 文档表示和
固定 1:1 RRF 组合在本开发分母上的晋升资格。

## 固定 A/B 指标

| 指标 | R2 lexical A | H2 hybrid B | 门槛结果 |
|---|---:|---:|---|
| Recall@20 | 16/20 | 16/20 | 未达到至少18且增加2 |
| Recall@8 | 16/20 | 16/20 | 无退化 |
| MRR@20 | 0.775 | 0.775 | 无退化 |
| 非字面 Recall@20 | 6/10 | 6/10 | 未达到至少8且增加2 |
| hard-negative Top-8 | 4/4 | 4/4 | 通过 |
| 显式空目标 | 4/4 | 4/4 | 通过 |
| 词面基线 Recall@8 | 4/4 | 4/4 | 通过 |

固定失败码为 `H2_RECALL_AT_20_GATE_FAILED` 和
`H2_NON_LITERAL_GATE_FAILED`。结果保持非 Gold、非生产资格、非 Patch。

## 聚合归因

- 20 个有目标场景中，目标名次改善 0、保持 20、变差 0；
- A miss → B hit 为 0，A hit → B miss 为 0；
- A/B 均未命中 4 条，且 4 条均属于非字面类别；
- 只有 7/28 条完整候选列表字节等同，说明向量 leg 实际改变了多数候选的组成或顺序；
- 但这些变化全部发生在目标之外，没有把四个漏失目标提升进 Top-20，也没有改变已命中
  目标的名次。

因此，失败不是模型未调用、索引未生效或融合未运行；在当前冻结表示下，向量信号没有
对目标产生有效增益。不能从聚合结果进一步断言问题单独属于模型、文档表示还是融合
权重，若要区分必须另立单一变量合同和新的开发分母。

## 工程结果

- 索引：733 个节点，冻结 batch 16，共 46 个 index inference batch；
- query inference：21 个有效 query，首个 query 额外重放一次，共 22 次；
- 总 inference call：68；向量重放一致；
- 模型加载约 5.4 秒，索引约 15.4 秒；
- query P50/P95 约 11/14 毫秒；
- 总运行约 33.5 秒，峰值 RSS 约 450 MB；
- 私有索引与逐项结果权限均为 `0600`，索引重新绑定可信树/profile 验证通过；
- 正式运行无网络调用，未修改数据、Oracle、算法或门槛。

## 停止规则

按预注册，本28条不得继续尝试 BGE base/large、Qwen、另一 instruction、pooling、
维度、量化、权重、窗口或 reranker，也不得依据本结果调整 RRF。若产品仍要探索混合
召回，应先提出一个可归因的单一变量假设，并使用新的独立开发分母；在此之前，R2
lexical 继续是已验证基线，H2 不晋升为产品默认路径。
