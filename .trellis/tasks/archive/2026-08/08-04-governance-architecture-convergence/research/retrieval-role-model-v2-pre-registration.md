# Retrieval 角色模型 v2 首次实验预注册

## 唯一变化

v2 只在 v1 系统提示中增加通用 TARGET 边界规则：

- TARGET 应是能够独立指代信息项、字段、节点类别或名称的最小完整名词短语；
- 排除外围操作动词、方向词、状态描述、目的说明和仅用于限定动作的附加成分；
- 不能把一个固定复合名称拆成失去独立业务含义的词片段；
- 不提供或引用 M5 的具体短语、场景或 Silver 答案。

模型、温度、thinking、JSON 合同、source binding、18条分母、一次合同重试、Silver、
Oracle v2、R1、五视图和全部门槛不变。

## 决策

- 全部门槛通过：只证明 v2 在暴露开发集上修复已知边界问题；停止在本集合调参，
  转入新未见树确认；
- 合同通过但 Recall@8、MRR或空目标失败：保持 FAIL，停止 v3 Prompt；下一方案必须
  评估容忍 super/sub-span 与非字面表达的节点检索表示或 hybrid retrieval；
- 合同失败：按模型合同错误归因，但仍停止本集合上的 Prompt 递增；
- 结果不得覆盖 v1，不能宣称生产资格。
